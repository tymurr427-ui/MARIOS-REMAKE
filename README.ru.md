# Super Plumber Bros

Браузерный 2D-платформер на чистом HTML5 Canvas и JavaScript, размещённый на GitHub Pages с бэкендом на Supabase для аккаунтов, прогресса и таблиц рекордов.

## Играть

Откройте `index.html` в браузере или сыграйте в онлайн-версию на GitHub Pages: **MARIOS-REMAKE**.

## Возможности

- **Платформер-экшен** — бегайте, прыгайте, собирайте монеты и уклоняйтесь от врагов и ловушек (шипы, дробилки, турели, лазеры, атакующие враги) на растущем числе уровней.
- **Встроенные уровни + редактор уровней** — создавайте собственные уровни прямо в игре (земля, платформы, движущиеся/односторонние/ледяные платформы, телепорты, рычаги и ворота, боссы, декорации, башни вверх) и делитесь ими с помощью короткого кода.
- **Уровни от игроков** — просматривайте, играйте и оценивайте уровни, созданные другими игроками («Мастерская»), с таблицей лучших времён прохождения для каждого уровня.
- **Персонализация / Магазин** — разблокируйте и надевайте скины, шапки (отдельно цвет и фасон), растительность на лице, тон кожи, очки и эффекты следа — покупая за внутриигровые монеты или открывая по уровню игрока.
- **Задания и достижения** — ежедневные задания, постоянные задания-вехи и полный список достижений, дающих опыт (XP) и монеты.
- **Прогресс игрока** — уровень игрока на основе опыта (XP) с системой престижа для тех, кто достиг максимального уровня.
- **Мультиплеер** — проходите уровни вместе с другими игроками в реальном времени.
- **Общий рейтинг и статистика** — монеты, время игры, смерти, убитые враги/боссы, созданные уровни и многое другое, с сортировкой по категориям.
- **Аккаунты через вход Google** — прогресс сохраняется в аккаунте (Supabase) и может быть экспортирован/импортирован в виде подписанного файла сохранения.
- **Локализация** — интерфейс доступен на польском и английском языках.
- **Адаптивный HUD** — автоматически увеличивается на больших экранах/4K.

## Технологии

- **Фронтенд:** чистый HTML5 Canvas + JavaScript (без сборки, без фреймворков)
- **Бэкенд:** [Supabase](https://supabase.com) (Postgres + Auth + Row Level Security) для профилей, пользовательских уровней, рекордов времени и каталога магазина
- **Хостинг:** GitHub Pages

## Защита от читов

Прогресс игрока (монеты, опыт, уровень игрока, купленные косметические предметы, время прохождения) проверяется **на стороне сервера** в Supabase с помощью триггеров Postgres и Row Level Security, а не просто доверяется клиенту:

- Прирост монет и опыта ограничен по скорости («бюджетом», который восстанавливается со временем), поэтому изменённый клиент не может выдать себе неограниченную валюту или мгновенно получить максимальный уровень.
- Показатели, которые должны только расти (заработанные монеты, смерти, убитые враги и т.д.), не могут уменьшаться.
- Покупки в магазине проверяются по серверному списку цен; разблокировка предмета без оплаты (или без нужного уровня) отклоняется.
- Время прохождения на время должно быть правдоподобным и может быть только улучшено, а не подделано произвольно в любую сторону.
- Экспорт/импорт сохранения подписан криптографически (HMAC), поэтому экспортированный файл сохранения нельзя вручную отредактировать и импортировать обратно.
- Редактирование официальных/встроенных уровней разрешено только аккаунту администратора проекта — это закреплено политикой базы данных, а не только проверкой на стороне клиента.
